# Battime → Telegram

Готовый Python-парсер для `battime.ru`.

Что делает:

1. Открывает главную страницу.
2. Ищет новости и определяет самую свежую по дате/времени.
3. Может фильтровать новости по Ростову.
4. Открывает страницу новости.
5. Забирает заголовок, текст и главное изображение.
6. Отправляет фото + текст в Telegram-канал.
7. Сохраняет URL в SQLite, чтобы не публиковать одну новость дважды.
8. Проверяет сайт каждые N секунд.

## 1. Создать Telegram-бота

В Telegram открой `@BotFather` и создай бота командой `/newbot`.

Скопируй полученный токен.

## 2. Добавить бота в канал

Добавь бота администратором в свой Telegram-канал.

В `.env` можно указать:

    CHANNEL_ID=@username_канала

Если канал приватный, используй числовой chat_id вида `-100...`.

## 3. Установка

Нужен Python 3.10+.

Windows:

    py -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt

Linux/macOS:

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

## 4. Настройка

Скопируй `.env.example` в `.env`.

Например:

    BOT_TOKEN=123456789:ABCDEF...
    CHANNEL_ID=@my_news_channel

`ROSTOV_ONLY=1` — публиковать только новости, связанные с Ростовом.

`ROSTOV_ONLY=0` — публиковать любую свежую новость с сайта.

`CHECK_INTERVAL_SECONDS=300` — проверка каждые 5 минут.

`MAX_ARTICLE_CHARS=0` — отправлять весь текст. Если поставить, например, `3500`, статья будет ограничена.

## 5. Запуск

    python main.py

После запуска в консоли появится примерно:

    Бот запущен.
    Проверка каждые 300 сек.
    Свежая новость: ...

## Важный момент

Парсер специально не зависит от конкретного имени CSS-класса вроде `.news-item`.
Он ищет ссылки на статьи, даты, `h1`, `og:image` и текстовые контейнеры по нескольким признакам.

Это делает его устойчивее к небольшим изменениям дизайна сайта.

Если Battime полностью поменяет HTML-разметку, селекторы в `parser.py` может потребоваться обновить.

## Публикация контента

Перед публикацией полного текста чужой статьи в публичный канал проверь права на перепубликацию. Более безопасный вариант — публиковать заголовок + краткий фрагмент + ссылку на оригинал.
